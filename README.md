# MLOps House Price Prediction - 23l2500

## Project Description

This project implements a house price prediction machine learning model using
a Random Forest Regressor. Git and GitHub are used for version control and to
maintain a clean and reproducible project structure.

## Project Structure

The project is organized into separate directories and configuration files
for managing the dataset, source code, trained model, and project dependencies.

- **data/** — Contains the raw housing dataset used for training the machine
  learning model. This directory is excluded from Git using `.gitignore`.

- **src/** — Contains the Python source code for the project. The main training
  script is `train_23l2500.py`, which loads the dataset, preprocesses the data,
  trains the Random Forest model, evaluates its performance, and saves the
  trained model.

- **model/** — Contains the trained machine learning model generated by the
  training script. The serialized model file is excluded from Git.

- **.gitignore** — Specifies files and directories that should not be tracked
  by Git, including the raw dataset, trained model files, Python cache files,
  and virtual environments.

- **requirements.txt** — Contains the Python packages required to install and
  run the machine learning project.

- **README.md** — Provides documentation about the project, its structure,
  installation requirements, and instructions for running the training script.
